ANVIL Core Technology

공격 로그에서 검증된 방어 룰까지

ANVIL은 WAF 로그를 수집하고, 요청을 정규화한 뒤, 공격 패턴을 룰로 만들고 검증해 안전한 룰만 배포하는 자가개선형 웹 방어 플랫폼입니다.

WAF Gateway

요청을 먼저 검사하고, 차단/허용 결과와 공격 로그를 남깁니다.

Analysis Pipeline

로그 수집, 정규화, 탐지, 룰 생성, 검증 작업을 비동기로 처리합니다.

Validation & Report

ZAP 테스트와 AI 리포트로 룰의 차단 근거와 개선 방향을 설명합니다.

Core Tech 01

WAF 기반 요청 수집과 방어 룰 배포

서비스 앞단에 WAF Gateway를 두고, 기존 CRS가 막지 못한 공격 로그를 분석해 새로운 방어 룰을 다시 배포합니다.

01

요청 진입

사용자 또는 공격자의 요청이 먼저 WAF Gateway로 들어옵니다.

02

기본 방어

Nginx + ModSecurity + OWASP CRS가 알려진 공격을 우선 차단합니다.

03

로그 수집

차단/허용 결과와 의심 요청 로그를 OpenTelemetry로 수집합니다.

04

룰 생성

분석 파이프라인이 공격 특징을 조건 기반 시그니처 룰로 변환합니다.

05

WAF 배포

검증과 승인 후 살아남은 룰만 WAF에 적용합니다.

Core Tech 02

정규화 + 검증 파이프라인

공격자는 인코딩, 대소문자, 주석 삽입으로 룰을 우회합니다. 그래서 원본 요청을 바로 비교하지 않고, 정규화한 뒤 탐지와 검증을 반복합니다.

Before
/search?q=%2555NiOn/**/SeLeCt
<script>alert(1)</script>
인코딩 · 대소문자 · 주석으로 난독화
After Normalize
union select
script alert
URL Decode → Lowercase → Comment 제거
A

Normalize

우회 표현을 같은 의미의 토큰으로 정리합니다.

B

Detect

SQLi, XSS 같은 공격 징후를 점수화합니다.

C

Validate

ZAP과 샌드박스/홀드아웃 데이터로 오탐을 확인합니다.

D

Deploy

성능이 확인된 룰만 WAF에 배포합니다.
