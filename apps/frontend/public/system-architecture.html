전체 흐름

  1. 요청 유입: 사용자의 정상 요청과 테스트 공격 요청이 `Nginx`로 들어온다.
  2. WAF 탐지: `ModSecurity`가 `OWASP CRS`와 생성된 커스텀 룰로 요청을 검사한다.
  3. 이벤트 수집: WAF 로그, API 로그, 차단 결과를 `OpenTelemetry Collector`가 수집한다.
  4. 분석 저장: Platform API가 요청을 정규화하고, 탐지 결과를 DB와 검색 저장소에 남긴다.
  5. 룰 개선: 탐지 실패·우회 사례를 기반으로 새 시그니처 룰을 만들고 검증한다.
  6. 승인 배포: 관리자 승인 후 룰을 WAF에 반영하고, 문제가 생기면 이전 버전으로 롤백한다.

구성 요소 역할

  • Admin Dashboard: 로그 조회, 룰 검증 결과, 승인/거절, 리포트 확인 화면.
  • Platform API: 수집, 정규화, 탐지, 검증, 룰 배포를 담당하는 메인 백엔드.
  • Normalizer: URL decode, unicode normalize, lowercase 등으로 탐지 가능한 형태를 만든다.
  • Signature Detector: 조건 트리 기반 룰로 SQLi, XSS, Path Traversal 등을 분류한다.
  • Redis + BullMQ: 룰 생성, 샌드박스 검증, AI 리포트 생성 같은 오래 걸리는 작업을 큐로 처리한다.
  • OpenAI / Gemini: 룰 초안, 우회 전략 추천, 사람이 읽기 쉬운 보안 리포트 생성에만 사용한다.
