CORE TECH 01

WAF 기반 요청 수집과 방어 룰 배포

엔빌의 첫 번째 핵심은 서비스 앞단에 보안 관문을 세우고, 실제 요청 흐름에서 차단 로그와 우회 로그를 확보하는 구조입니다.

왜 WAF Gateway가 먼저인가?

공격은 애플리케이션 코드에 도달하기 전에 먼저 WAF를 통과합니다. 여기서 기존 CRS가 막은 요청과 통과한 의심 요청이 모두 분석 재료가 됩니다.

Nginx ModSecurity OWASP CRS WAF Log
User Request → Nginx → ModSecurity Rule Check → OWASP CRS → Allow / Block / Log

CORE TECH 02

정규화 + 검증 파이프라인

두 번째 핵심은 공격 문자열을 그대로 믿지 않고, 우회 표현을 같은 의미로 정리한 뒤 룰을 만들고 검증까지 반복하는 과정입니다.

1
Normalize URL Decode, Unicode Normalize, Lowercase 등으로 우회 표현 정리
2
Detect 정규화된 요청에서 SQLi, XSS 등 공격 의심 패턴 탐지
3
Rule Generate 단순 정규식이 아니라 조건 트리 기반 시그니처 룰 생성
4
Validate Sandbox, Holdout, OWASP ZAP으로 차단률과 오탐률 검증
5
AI Report 공격 의도와 룰 개선 방향을 관리자에게 설명
6
Deploy 승인된 룰만 WAF에 적용하고 배포 이력 관리
